# LoRA｜低秩适配

LoRA（Low-Rank Adaptation）是一种参数高效微调方法。它冻结预训练模型的原始权重，将选定层的权重更新表示为两个小矩阵的乘积。这样可以用较少的可训练参数，让已有模型适应新任务、数据或输出行为。

## 1. 为什么 LoRA 能节省训练参数

设一个线性层的原始权重为 $`W_0 \in \mathbb{R}^{d_{\mathrm{out}}\times d_{\mathrm{in}}}`$。全量微调时，$`W_0`$ 的每个元素都可以更新。使用 LoRA 时，$`W_0`$ 冻结，训练得到的修正量叠加到原权重上。

```math
W_{\mathrm{eff}} = W_0 + \Delta W,
\qquad
\Delta W = \frac{\alpha}{r}BA
```

| 符号 | 形状或类型 | 作用 |
| --- | --- | --- |
| $`W_0`$ | $`d_{\mathrm{out}} \times d_{\mathrm{in}}`$ | 冻结的预训练权重 |
| $`A`$ | $`r \times d_{\mathrm{in}}`$ | 可训练矩阵，把输入映射到 $`r`$ 维 |
| $`B`$ | $`d_{\mathrm{out}} \times r`$ | 可训练矩阵，把中间表示映射到输出维度 |
| $`r`$ | 正整数 | 中间维度，也是更新量的秩上限 |
| $`\alpha`$ | 标量超参数 | 通过 $`\alpha/r`$ 缩放修正量 |

> *前向计算。* 忽略偏置时，输入 $`x`$ 一路经过原权重得到 $`W_0x`$，另一路依次经过 $`A`$ 和 $`B`$，得到适配器输出 $`B(Ax)`$。把适配器输出乘上 $`\alpha/r`$ 后加到原分支的输出上，即得到该层的最终输出。

训练时，这个线性层只更新 $`A`$ 和 $`B`$。因此，按权重矩阵计，全量微调有 $`d_{\mathrm{out}}d_{\mathrm{in}}`$ 个可训练参数，LoRA 有 $`r(d_{\mathrm{in}}+d_{\mathrm{out}})`$ 个。当 $`r`$ 远小于输入和输出维度时，降幅明显。**部署单个适配器时，可以把训练得到的 $`\Delta W`$ 合并进原权重，沿用原来的线性层做推理。**

## 2. 秩与 LoRA32、LoRA64

更新量经过一个 $`r`$ 维的中间表示，因此它的秩最多为 $`r`$。提高 $`r`$ 会扩大可表示的更新范围，同时增加可训练参数。

```math
\operatorname{rank}(\Delta W) \leq r
```

LoRA32 和 LoRA64 通常表示秩参数 $`r`$ 分别取 32 和 64。以下以一个 $`4096\times4096`$ 的线性层为例。

| 配置 | 秩参数 | 本层可训练参数 | 占全量微调的比例 |
| --- | --- | ---: | ---: |
| 全量微调 | — | 16,777,216 | 100% |
| LoRA8 | $`r=8`$ | 65,536 | 约 0.39% |
| LoRA32 | $`r=32`$ | 262,144 | 约 1.56% |
| LoRA64 | $`r=64`$ | 524,288 | 约 3.13% |

**在相同的目标层上，LoRA64 的适配器参数量是 LoRA32 的两倍。** 秩增加带来的任务收益可以用验证集指标衡量，例如 VLA 在新机械臂上的任务成功率。

## 3. 后训练、微调与 LoRA 的关系

| 概念 | 含义 |
| --- | --- |
| 后训练（post-training） | 强调训练在整体流程中的位置，通常指基础模型预训练后的指令训练、对齐或任务适配。 |
| 微调（fine-tuning） | 强调从已有模型权重出发继续训练，使模型适应目标任务、领域或行为。 |
| LoRA | 指定如何更新所选层的权重，即训练低秩适配器并冻结这些层的原始权重。 |

> *论文用语。* 有些论文把 post-training 专指通用模型的指令训练和偏好对齐，并把后续面向具体任务或设备的适配单独称为 fine-tuning。两者并列时，可以根据论文给出的训练流程判断各自的范围。

### 常见训练用途

| 用途 | 使用的训练数据或信号 | 例子 |
| --- | --- | --- |
| 监督微调（SFT） | 输入与目标输出的配对数据 | 让 VLM 学会回答特定类型的图像问题 |
| 领域适配 | 领域原始文本或领域问答对 | 用领域文本做继续预训练，或用问答对做 SFT |
| 偏好对齐 | 对同一输入的成对回答及偏好标签 | 用 DPO 目标更新 LoRA 适配器 |
| 下游任务适配 | 目标图片、机器人示范等任务数据 | 让图像生成模型学习特定风格，或让 VLA 适应新机械臂 |

**VLA 例子。** 让预训练 VLA 适应实验室里的新机械臂时，可以用该机械臂的示范轨迹，以当前观测和指令为输入，以示范动作为监督信号。在 Transformer 的注意力投影层中训练 LoRA。如果需要新增动作预测头，也可以同时训练动作头。按流程，这是预训练后的下游适配。按监督信号，这是监督微调。LoRA 描述的是主干的参数更新方式。
